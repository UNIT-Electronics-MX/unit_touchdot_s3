### **9.2 Source Hierarchy and Revision Notes**

This product reference consolidates the maintained repository README, hardware
README, V0.1.2 schematic and mechanical/topology artwork, V0.2.0 pinout
artwork, and the existing programming documentation. If values conflict, use
the newest released hardware source for the applicable board revision and
verify the signal on the physical board before connecting external hardware.

The serial D0/D1 Arduino labels differ between some legacy text and the current
V0.2.0 pinout artwork. This document follows the V0.2.0 artwork for its header
table and retains the underlying GPIO numbers so users can identify the signal
unambiguously.
